# RISE Developer Infrastructure WG

## About RISE

[RISE](https://riseproject.dev) is a collaborative, industry-led initiative under the Linux Foundation that accelerates open-source software development for the RISC-V architecture.

## Charter

This working group focuses on software and services to support open-source developers - both RISE members and the broader open-source community. Our objectives are to:

- Help collaboration across companies to avoid duplication of work
- Build and maintain developer infrastructure (build farms, board farms, developer tools) for RISC-V
- Communicate on the readiness of the respective ecosystems
