# RISE OpenJDK CI (inactive)

## Summary

The RISE Build Farm hosted an OpenJDK post-commit builder for RISC-V during 2024Q1.

As of April 2024, this has been moved to Scaleway's RISC-V infrastructure, also funded by RISE.
